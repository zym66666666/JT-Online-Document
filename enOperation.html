I. Overview

CoolClean App is a handheld configuration tool developed by Jiutian Innovation Technology to work with Jiutian's self-developed outdoor cleaning robots. It aims to make cleaning simpler and more convenient, promoting the digitalization and unmanned transformation of cleaning in micro-circulation areas such as large enterprise group cultural and creative parks, industrial parks, etc. CoolClean App mainly works with self-developed unmanned cleaning vehicles to achieve remote cleaning control, generation of cleaning data reports, remote device monitoring, etc.

II. Software Description

2.1 Software Running and Installation Environment

This App runs on Android 9.0 and above, Huawei HarmonyOS 1.0 system, iOS 13.0 and above. After installing the App, click the icon on the phone's home screen to run it and perform the required software operations.

2.2 Main Features of the Software

CoolClean App can bind to CoolClean's self-developed unmanned cleaning vehicles with one-click scanning. After binding, users can remotely view device information and status to obtain vehicle operation status, remotely set vehicle terminal parameters, build maps, create cleaning plans, view historical cleaning reports, etc.

3.2.2 Cleaning Plan Creation

1
Click the device operation page menu, click Cleaning Plan, enter the page and click the Add button
2
Select cleaning method, select cleaning partition task
3
The meanings of partition content are as follows:
  • Select Partition: Select the area that needs to be cleaned after partitioning
  • Select Times: Set the number of cleaning cycles, range (1-10)
  • Cleaning Intensity: Baffle height, low (cigarette butts, scattered leaves, etc.), medium (accumulated small leaves, etc.), high (accumulated large leaves, etc.), automatic (water bottles, etc.)
  • Cleaning Method: Includes edge cleaning and coverage cleaning. If you want to clean edges first and then cover, you can add edge cleaning first and then continue to add a coverage task
4
After selecting the tasks to add, click Save and name
Note: The device cleaning order is based on the order in which you add tasks
5
Supports combination of partition and manually recorded paths for cleaning operations, just click Path and select the path name
Note: For safety reasons, manually recorded paths should not exceed partition boundaries

3.3 Cleaning Operations

When the user has bound the device, created the map and cleaning plan, they can perform cleaning actions.

1
Select the corresponding cleaning plan in the upper left corner,
2
Then click the start button icon in the middle of the page, and the vehicle will clean according to the cleaning path generated by this plan. At this time, the start button changes to the task pause button.
3
Click the pause button icon, and the cleaning vehicle can pause the current task and stay in place.
4
Long press the start or pause button icon to end the current plan task in advance, and the vehicle will return to the set charging point.
5
In any state of the vehicle, click the recall button, and the vehicle will immediately stop the current task and return to the charging point.

3.4 Device Information

3.4.1 View Map List Information

5
Click Map Management in the menu bar to jump to view the device's map list.
6
Click the corresponding map to jump to view map details. Includes map creation start time, map area.
7
Swipe left on the corresponding map creation record to display two setting options: [Default] [Delete]. Click Default to set this map as the device's default display map. Click Delete to delete this map.

3.4.2 View Cleaning Task Information

9
Click View Cleaning Task Information in the menu bar to jump to view the device's cleaning task list.
10
Click on a cleaning plan to jump to view cleaning plan details, and you can rename, edit area paths, waypoints, and times of the plan.
11
Swipe left on the corresponding cleaning task to display two setting options: [Default] [Delete]. Click Default to set this cleaning task as the default cleaning task for the device's default map. Click Delete to delete this cleaning task.
12
Click the + button in the lower right corner of the page to create a new cleaning task

3.4.3 View Work Records

13
Click Work Records in the menu bar to jump to view the device's work records.
Note: Work records include: Normal Cleaning, Abnormal Cleaning, Normal Map Creation, Abnormal Map Creation
14
Click the corresponding work record to view work record details

3.4.4 Device Remote Settings

15
Click Vehicle Settings in the menu bar to jump to view device details, general settings, low battery return settings, turn signal settings, and device volume settings, etc.
16
Click General Settings to jump to device settings, where you can set turn signals, low battery return switch, and device volume.

3.4.5 Scheduled Tasks

1
Enter the device function list and click [Scheduled Tasks] to enter the scheduled tasks page
2
Set the scheduled task time, click to pop up the task start time window, select time from 00:00 to 24:00.
3
Set the repetition frequency of scheduled tasks, click to pop up options from "Monday to Sunday", multiple selections are allowed. When all are selected, it means daily repetition. When multiple options are selected, it means scheduled cleaning repeats on those days of the week. When none are selected, it means the scheduled task executes only once.
4
Select cleaning plan, click to jump to the cleaning plan list.
5
Finally save the scheduled task plan. After successful saving, when the vehicle is properly configured, the vehicle can automatically clean at the start time of the scheduled task.
Conditions for automatic cleaning via scheduled tasks:
1) The vehicle needs to remain in standby state
2) The vehicle needs to have a charging point set, and in the webApp, set the departure and return routes from the charging point to the path starting point, and the vehicle must always be at the charging point.

3.5 Cleaning Reports

Click Reports in the App's bottom menu bar to jump to the reports page, displaying the device's cleaning reports.
2
Click on a cleaning report record to view report details.
